# 世界設定・シナリオ — ゆりかごの双刃（仮） 第0.1版

> ネタバレ全開の制作資料です。固有名詞はすべて仮。

---

## 1. 主題

**「癒やしすぎることは、傷つけることに似ている」**

- 世界規模では：傷を許さない聖女の慈悲が、死ねない・朽ちない・終われない世界を作った。
- 家族規模では：息子を失いたくない母の手が、息子を強くし、同時に縛ってきた。
- ゲームシステムでは：回復魔法がそのまま攻撃になり、回復しすぎると自分が傷つく（過治癒／癒え焼け）。

物語・世界・システムの三つが同じ一文を語る構造にする。
結末は「創造と再生」「得るために失う」という、90年代のアクションRPGが好んだほろ苦さを狙う。

## 2. 世界

### 2.1 ユグレシア

大陸ひとつ分の小さな世界。300年前の「裂け戦（さけいくさ）」で大地も人も深く傷ついた。

### 2.2 慈雨の樹（じうのき）

- 戦の終わり、施療師エウラリアは自らを種として大陸中央に一本の樹を生やした。
- 樹は**慈雨**と呼ばれる霧雨を降らせる。浴びた傷は塞がり、病は退き、荒れ地は緑に戻った。
- 人々は彼女を「止まずの聖女」と呼び、**慈雨教会**が生まれた。

### 2.3 繁り病（しげりやまい）

300年、雨は一度も止まなかった。そして癒やしは**飽和**した。

| 現象 | 内容 |
|---|---|
| 繁り | 草木が一晩で家を呑む。切っても切り口から倍の芽が出る |
| 瘡蓋（かさぶた） | 掘った鉱山が「大地の傷」として塞がり、坑夫ごと結晶に閉じ込める |
| 癒え残り | 死んだはずの者が朽ちず、起き上がる。痛みだけが残っている |
| 過癒 | 生き物の体が治りすぎて膨れ、形を失う |

教会はこれを「恵みが深まった証」と説く。人々は不安を口にできない。
墓は必要なくなり、弔いの職である**送り人**は廃業寸前。

### 2.4 用語

| 用語 | 意味 |
|---|---|
| 慈力 | 慈雨を体に溜めて使う力。施療師の資質 |
| 過治癒（オーバードライブ） | 飽和を超えて慈力を注ぎ、生命をほどく技。教会の禁術 |
| 飽和 | 生命が受け止められる癒やしの限界 |
| 崩壊 | 飽和を超えた生命がほどける現象 |
| 送る | 癒え残りを本当に死なせること |
| ルク | 通貨。戦前の鉄貨（錆びない鉄はもう採れない） |

## 3. 登場人物

### 3.1 グレン（主人公・18歳）※名前変更可

- 辺境ハルネ村の鍛冶屋の息子。口数は少ないが、思ったことは顔に出る。
- 身の丈ほどの鉄塊を**左右一本ずつ**振るう。村では「怪力のせがれ」で通っている。
- **怪力の理由**：生まれた時、息をしていなかった。母が禁術・過治癒で無理やり命を繋ぎ、その後も病弱な体を癒やし続けた結果、筋肉と骨が「治りすぎて」いる。
- **代償**：自然治癒力がほとんど無い。擦り傷ひとつ、母の手か慈雨が無ければ塞がらない。→ ゲーム上「自動回復なし」の理由。本人は知らない。
- 好物：母の麦がゆ。嫌い：子ども扱い。
- 右手の剣「暁」は父の形見、左手の「宵」は父の真似をして自分で打った不格好な習作。

### 3.2 ミレイユ（母・38歳）

- 村の施療師。朗らかで世話焼き、よく食べよく笑う。怒ると拳が出る。
- **素手が強い理由**：施療院仕込みの「整骨拳」。本来は外れた骨を一撃で接ぐ治療術だが、逆に使えば外せる。本人いわく「治せるってことは壊し方も知ってるってこと」。
- **過去**：20年前、雪の施療院で次代の聖女候補として育てられた。禁術の書を読み、院を出奔。旅の剣士ヴォルクと出会い、グレンを産む。
- **秘密**：息子の命が自分の癒やしと慈雨に依存していることを誰にも言っていない。雨が止めば息子は死ぬかもしれない。だから彼女は、世界がおかしいと知りながら、樹を止めたいとは言えなかった。
- 口癖：「はいはい、じっとして」「母さんを誰だと思ってるの」

### 3.3 ヴォルク（父・生きていれば45歳）

- 流れの双剣使い。10年前、「樹を見てくる」と言って暁の片割れを残し、旅立ったきり。
- 真相：グレンの体の秘密に気づき、**息子が雨なしで生きられる方法**を探して樹に辿り着いた。聖女に取り込まれ、樹の番人として10年間「癒やされ続けて」いる。

### 3.4 ノエ（送り人・24歳）

- 仕事のない墓掘り。円匙（シャベル）を背負い、行商で食いつないでいる。皮肉屋。
- 各地の焚き火に現れ、品物と噂を売る。癒え残りを「送る」依頼を出す。
- 物語上の役割：「死ねること」の価値を語る唯一の人物。ミレイユとは考えが合わないが、妙に気が合う。

### 3.5 オルガ（雪の施療院長・61歳）

- ミレイユの師。厳格。禁術を封じ、弟子を失った人。
- 繁り病の進行で院の患者たちが「過癒」に呑まれ、彼女自身も正気を半ば失っている。
- 第4章ボス。倒された後、正気に戻り、過治癒の本当の使い方（慈雨返し）を授ける。

### 3.6 ベネディクト（慈雨教会 司祭長・50代）

- 穏やかな笑顔の狂信者。「誰も失わない世界」を本気で善と信じている。
- 妻子を戦後の疫病で亡くした過去。悪人ではない。
- 第5章で対峙（戦闘は配下の「抱擁の聖像」）。最後は樹に自ら取り込まれることを選ぶ。

### 3.7 エウラリア（止まずの聖女）

- 樹の心臓で300年、祈り続けている少女。意識はほぼ夢の中。
- 「もう誰も痛くないように」という一念だけで雨を降らせ続けている。
- 終章ボス。倒す＝彼女をようやく眠らせること。

## 4. 章立て

### 序章「雨漏り」— ハルネ村（40分）

- 朝。母に叩き起こされ、朝食、鍛冶場の手伝い。操作チュートリアル。
- 裏山の水車小屋が一晩で茂みに呑まれる。水車番の老人を助けに行く（戦闘チュートリアル、焚き火の説明）。
- 老人はすでに繁りに呑まれ、怪物化している（**ボス：茂みに呑まれた水車番**）。斬っても再生する。母が初めて息子の前で**過治癒**を使い、老人は花びらになって散る。
- 「母さん、いまの何」「……あとで話すわ」
- 村に戻ると、繁りは村の半分に達している。教会の巡回司祭は「恵みです、祈りなさい」としか言わない。
- グレンは父の言葉を思い出す。「樹を見てくる」。樹へ行けば何かわかる。
- 母は止めるが、止めきれず、「あんた一人じゃ擦り傷も治せないでしょ」と同行。

### 第1章「溺れ森」— 苔むす街道〜溺れ森（80分）

- 街道は緑に沈みかけている。ノエ初登場（番犬の癒え残りに追われている）。
- 森の集落では、狩人たちが獲物を「殺せない」ことに苦しんでいる。射ても射ても治る。
- 森の主・千年角の大鹿は、狩人の長が若い頃に仕留め損ねた相手。300年分の角を背負って苦しんでいる。
- **ボス：千年角の大鹿**。倒すと、長は「やっと終わらせてやれた」と泣く。
- グレンに初めての疑問：「治るのは、いいことじゃないのか」

### 第2章「大地の瘡蓋」— 鉱山都市ガルドン（100分）

- 最初の町。炉が使える。鉄の産地だが、坑道が「塞がる」せいで鉄が採れず寂れている。
- 鍛冶屋の息子として、グレンは町の老鍛冶に認められ、鍛造を解禁。
- 坑道の奥には20年前に閉じ込められた坑夫たちが癒え残りとなって今も掘り続けている。
- **ボス：鉱山の瘡蓋竜**（大地の傷口そのものが竜の形に固まったもの）。
- 竜を砕くと坑道が開き、町に鉄が戻る。だが教会の兵が「大地を傷つけた」としてグレンたちを追い始める。
- 夜の焚き火。グレンが転んで擦りむいた膝を、母が当たり前のように癒やす。ノエがそれを見て眉をひそめる。「……あんた、その子の傷、いつから治してる？」

### 第3章「不死の入江」— 港町セルカ（100分）

- 魚が死なない港。網の中で永遠に跳ね続ける魚。食えない、売れない。
- 沖には100年前の戦船が沈まずに漂っている。船長ガラハドは、戦が終わったことを知らない。
- ミレイユが「手当て」を習得（港の老婆から、慈力を使わない普通の包帯の巻き方を教わる。→ 結末の伏線）。
- **ボス：不沈船長ガラハド**。3度倒して送る。最期に「……陸は、平和か」「はい」「そうか。では下船を許可する」
- 船長の航海日誌に、10年前に乗せた双剣の剣士の記述。父は北の施療院を経て樹へ向かった。

### 第4章「雪の施療院」— 北嶺（100分）

- ミレイユの故郷。彼女は明らかに行きたがらない。
- 院は半ば凍り、患者と修道士は過癒で異形化している。「過癒の施療師」は善意でグレンを癒やし殺そうとする。
- 書庫でグレンは自分の出生記録の写しを見つける。**死産。禁術による蘇生。自然治癒力の欠如。**
- 母子の最大の衝突。「なんで黙ってた」「言えるわけないでしょう！」
  - ここから次の焚き火まで、**ミレイユが離脱**。グレン単独、回復は薬のみの区間（15分）。プレイヤーに母の不在を体で理解させる。
- 院長室。オルガは錯乱し、「あの子を返しなさい」とグレンに過治癒を浴びせる。危機に母が戻る。
- **ボス：施療院長オルガ**。
- 正気に戻ったオルガ：「ヴォルクはここへ来た。お前の息子が雨なしで生きる術を尋ねに。私は答えた——無い、と。聖女に訊くしかない、と」
- 父は息子を捨てたのではなかった。
- ミレイユは「慈雨返し」を授かる。母子、和解というより「休戦」。

### 第5章「慈雨の樹」— 聖都〜大樹（100分）

- 聖都は樹の根元。人々は幸福そうに、ゆっくりと樹に呑まれている。
- ベネディクト：「止めればその子は死ぬ。母親なら、わかるはずだ」。ミレイユは即答できない。
- グレン：「母さんが決めることじゃない。俺の体だ」
- 樹の幹を登る。中腹に、樹皮に半身を埋めた双剣の番人。
- **ボス：樹の番人ヴォルク**。意識は無い。剣筋だけが残っている。グレンの連斬は父の型の写しであり、全攻撃が「見切れる」。プレイヤーが10時間で身につけたジャスト回避の総決算。
- 撃破後、一瞬だけ正気が戻る。「……でかくなったな。剣は、二本とも振れるか」「振れる」「なら、いい」
- 父は**送られる**。暁の片割れが手に入り、真打「暁」へ打ち直し可能に。

### 終章「ふたば」— 樹の心臓（60分）

- 樹冠。雨の源。眠る少女エウラリア。
- **ボス：止まずの聖女エウラリア**
  - 第一形態：聖女の夢。攻撃はすべて「回復」。プレイヤーを過剰生命→癒え焼けに追い込む。
  - 第二形態：大樹の心臓。ここで母の慈力回復が止まる（雨の源を断ち始めたため）。残りの慈力と薬で戦い抜く。
- 撃破。雨が止む。300年ぶりの晴れ間。
- グレンが倒れる。全身の古傷が一斉に開く。
- ミレイユは癒やそうとするが、慈力はもう無い。彼女は泣きながら、港で習った**ただの包帯**を巻く。「じっとして。……じっとしてて」
- 暗転。

### エピローグ

- 季節がひとつ過ぎたハルネ村。茂みは枯れ、畑が戻っている。
- ノエが村外れに最初の墓を掘っている。墓標は一本の鉄塊。「久しぶりの仕事だよ。腕が鳴るね」
- 鍛冶場。グレンが槌を振るっている。腕には、**初めて自分の力で塞がった傷跡**。
- 母が朝食に呼ぶ。「冷めるわよ」「いま行く」
- 画面には双葉がひとつ、土から顔を出している。慈雨の無い世界で初めて、自力で芽吹いた草。
- タイトルロゴ。**ゆりかごの双刃（ふたば）**。

（母は生存。慈力は失われ、彼女は「普通の手当てしかできない施療師」として生きる。）

## 5. トーンと演出方針

- **日常は明るく、世界は静かに怖い**。母子の掛け合いは軽妙に、繁り病の描写は淡々と。
- 残酷描写はしない。敵は血ではなく花・苔・結晶になって散る。
- 台詞は短く。1ウィンドウ18文字×3行、ひらがな多め。行間で語る。
- 母子漫才の定番ネタ（寝癖、好き嫌い、嫁の話）を章ごとに1つ。終盤でそれが効いてくる。
- 音楽の方向：民族調の笛と弦、戦闘は太鼓主体で疾走感、町はワルツ。終章は序章の朝の曲の変奏。
